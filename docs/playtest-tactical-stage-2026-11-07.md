# 霧の古城 — クォータービュー試遊ステージ（2026-11-07）

## 目的と範囲

ユーザーが好感触を示した、クラシックなタクティカルRPGを思わせる**オリジナルの斜め見下ろしドット絵**を、1ステージだけ実際に操作して評価するための候補。
`tactical-stage.html` から独立して起動する。既存の探索本編、GPS連携、装備、所持品、セーブには接続しない。
既存の Visual Canon をこの候補で更新したことにはしない。

## 最小プレイループ

1. 未踏の北の丘陵で画面タップ／「先へ進む」を使い、石橋と階段を進む。
2. 4地点目の到達で霧の古城を発見する。遠くに描かれている城を見ただけでは発見扱いにしない。
3. 古城門から守護者戦へ。予兆を見て「身を守る」と次の「斬る」を組み合わせる。
4. 勝ったら宝物庫で鐘鉄を任意に回収する。回収時点では戦利品は未確定。
5. 生きて野営地へ戻った時だけ鐘鉄の持ち帰りが確定する。途中撤退と敗北では確定しない。

操作はタップ／ボタン／キーボード（方向キーまたは Enter、探索中 Escape で撤退）。
探索移動と戦闘はステージ内の決められた遷移であり、ターン制戦術ゲームへの全面転換は意図しない。

## 試作の画像

`assets/tactical-stage/` の背景3枚と冒険者・守護者のドット絵2枚は、直前のTactics Ogre風CM検討で生成した**本プロジェクト向けオリジナルAI画像**の軽量WebP版。
既存のゲーム、キャラクター、UI素材の画像を転用していない。レビューで受け入れられた場合にのみ、プロジェクトの本編グラフィック方針への採用を別途検討する。

## テストと未解決の評価

- `node --test test/tactical-stage-core.test.js`：未知地点の発見、防御→反撃、生還時のみ取得、撤退、敗北を検証。
- `npm run playtest:tactical-stage`：360 / 390 / 430pxのスマホ画面と1280pxのPC画面で、実タップ・移動・発見・戦闘・戦利品持ち帰り・再挑戦・コンソールエラー・画面はみ出しをチェック。ChromiumのあるCI環境で実行。
- 今回のプロトタイプは「絵を1枚ずつ進める単線の短い探索」。自由移動、敵AI、位置情報連動、装備反映は未実装。**1ステージの絵・操作感の評価が目的**。

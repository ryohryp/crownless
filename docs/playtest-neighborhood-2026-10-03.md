# 近所と自分の拠点を育てる試作

2026-10-03。ユーザーの「Ornaでは、自分の拠点や領域が育ち、近所がゲーム世界になることが面白かった」という回答を優先した開拓ループ。

## 参考と実装範囲

- [Northern Forgeの公式紹介](https://northernforge.com/) は実在の場所の探索とOrigin Townの建設を紹介している。
- [Ornaの2024-10-29更新](https://playorna.com/releases/1.160.0/) はOrigin Townの施設から始めるSettlementの確保・防衛を紹介している。
- Crownlessでは、個人のPvE開拓と機能を持つ建物をまず実装した。外部の競争、防衛戦、日次報酬は今回の範囲外。
- 単なる建物ボタン追加との2候補でJevの事前評価を実行。`jev_status=ok`, `jev-1.13.0`, `next_action=neighborhood`, confidence `0.96`, probabilities `{neighborhood:0.98, buildings_only:0.02}`, usage `623/43`, request `req_01a0fdb889ad79389d904fb2f6650afe`。選択は助言。

## 遊べる流れ

1. 最初の一戦から生還し、木材2・石材1を持ち帰る。
2. 鍛冶小屋を建てる。武器の補強費が実際に鉄片2減る。
3. 土地の主を倒して生還すると、その区画だけが領域になり地図に旗が立つ。
4. 開拓済みの区画を再訪すると、戦利品を持ち帰った時の建材が各1増える。
5. 木材4・石材2と領域1で住居を建てる。村の窓明かりと最大体力+4が増える。
6. 拠点の命名と周辺の発見。再読み込み後も村・建物・各区画の開拓状態が残る。

地図は発見済みの個別区画を表示する。位置は起点から約400m単位の相対区画。方向が同じでも異なる区画は独立し、GPS誤差を含む境界では確定しない。区画内の遠征内容は既存の4地形を再利用している。地図は局所スクロール、最大64区画。起点は既存の端末内保存を継続し、最初の観測から約100mに丸め、再読み込みで同じ基準を使う。正確な移動軌跡は記録しない。

旧セーブは地形の発見を隣接区画へ移行するが、古い踏破記録だけで区画の領有や建材を付与しない。バックアップには起点の座標を含めない。過去の地域メモは残すが、現在の画面では旧座標メモ・固定デモ地域の補足UIを使用しない。

# 敵：Skirmisher

- Maintains distance and creates telegraphed ranged pressure
- Locks aim early enough that movement out of the line creates a punish opportunity
- Uses a narrow retreat-ready posture and a clearly readable ranged tool
- Must read as a Skirmisher through silhouette and stance before labels
- Does not use the Rusher's lunging mass or the Guard's broad shield silhouette
- Represents the ordinary enemy role rather than the named target 沼鴉

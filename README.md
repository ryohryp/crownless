# Crownless — 霧の向こうへ

**15分遊んだあと、もう1回遠征したくなるか。**

Explore → Fight → Loot → Return alive → Improve → Explore farther

`AGENTS.md` を基準にした、スマートフォン向けの小さな遠征RPGです。霧の中の土地を見つけ、敵の予兆を読み、戦利品を生きて持ち帰ります。

## 遊ぶ

Node.js で起動します。追加パッケージのインストールは不要です。

```sh
npm start
```

[http://localhost:4173](http://localhost:4173) を開き、「まずは体験する」を選択。

1. 囁きの森へ遠征。敵の次の行動を見て、防御・回避・攻撃を選ぶ。
2. 傷を引き受けて遺品を拾うか、休むかを選ぶ。
3. 戦闘の合間に帰還し、鉄片と装備を確保する。倒れると今回の背嚢を失う。
4. 焚き火で装備を変更し、旅装を補強する。
5. 別の道の散策を体験して塔や湿原を発見する。二つの土地を踏破したら、灰冠の廟へ。

各土地は5場面・3戦闘。さらに深層3まで挑めます。現実の時間制限はなく、行動を選ぶまで敵は動きません。戦闘途中でも再読み込みして続けられます。

## 現実の散策

「現実の散策モード」で、立ち止まって起点を設定します。その起点からおよそ150〜270m以上離れた広い領域で、移動の方向に応じた架空の土地を発見します。歩数や累積距離で通貨は得られません。発見後の遠征は、自宅などの安全な場所から行えます。

- 行き先の指示や実在施設への進入は求めません。地図は架空の模式図です。
- 現在地は明示操作時にだけ取得。精度不足や検出できた移動中の観測は採用しません。
- 正確な座標はアプリから送信せず、保存もしません。基準位置はページを閉じると消えます。
- 保存する発見情報は4種の土地IDのみ。移動軌跡、住所、実在施設は扱いません。
- 体験と散策は別セーブ。位置情報を拒否しても体験モードで全ループを遊べます。
- スマートフォンの実GPSにはHTTPSでの配信が必要です。開発サーバーはこのPCのloopback限定です。

## 実装と確認

入口は `index.html` → `expedition.html`。ゲーム本体は `src/slice-engine.js`、画面は `src/slice-app.js`、オリジナルのSVG風景は `src/slice-art.js`、スタイルは `slice.css` です。外部API、外部フォント、ビルド工程はありません。保存は専用キーのlocalStorageで、旧セーブとは独立しています。

```sh
npm test
node --test test/slice-engine.test.js test/slice-app.test.js
```

新規テストは生還と損失、装備差、最終地点への到達、深層、途中保存、GPS精度・移動・遅延応答、保存失敗とタブ競合を確認します。ゲームの面白さは自動テストでは判定できません。

[今回のプレイ確認記録](docs/playable-slice-playtest.md) に、実画面で確認した範囲と次の実機プレイの問いを記載しています。

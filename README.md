# Crownless — 霧の向こうへ

**15分遊んだあと、次の素材を集めて新しい装備を作りたくなるか。**

Explore → Fight/Gather → Return with materials → Smith crafts → Equip → Explore farther

`AGENTS.md` を基準にした、スマートフォン向けの小さな遠征RPGです。霧の中の土地を見つけ、敵の予兆を読み、戦利品を生きて持ち帰ります。

設計・ADR・プレイテスト記録の権威関係は [`docs/README.md`](docs/README.md) に整理しています。現行ゲームプレイの補助仕様は [`docs/gameplay-spec.md`](docs/gameplay-spec.md) に集約しています。古い文書が `canonical` と名乗っていても、現在方針は `AGENTS.md` と新しい未supersede ADRを優先します。

## 遊ぶ

Node.js で起動します。追加パッケージのインストールは不要です。

```sh
npm start
```

[http://localhost:4173](http://localhost:4173) を開き、「まずは体験する」を選択。

1. 囁きの森へ遠征。敵の次の行動を見て、防御・回避・攻撃を選ぶ。
2. 傷を引き受けて遺品を拾うか、休むかを選ぶ。
3. 戦闘の合間に帰還し、鉄片と地域素材を確保する。倒れると今回の背嚢を失う。
4. 「装備」で鍛冶師に交代し、倉庫の素材から装備を作る。旅人に戻して装備を試す。
5. 別の道の散策を体験して塔や湿原を発見する。二つの土地を踏破したら、灰冠の廟へ。

現在の生産試作では「狼牙」2個＋鉄片4個で鍛ち牙の短剣、「鐘鉄」2個＋鉄片4個で番人の盾、「霧葦」2個＋鉄片4個で葦の長弓を鍛冶師が製作できます。鍛冶師の画面では、**架空のNPCからの製作依頼**も繰り返し引き受けられます。素材と鉄片を使ってNPCへ納品し、冒険者がその地域で敵と戦い無事に帰還すると、役に立った知らせ・鉄片の代金・次の同地域遠征で薬草+1の支援を受け取れます。依頼は実プレイヤーの注文ではなく、非同期な仕事の手応えを試すローカル版です。敵から完成装備は出ず、初期貸与装備と既存セーブ品は例外として残ります。1アカウント3キャラ枠・共通倉庫は今は端末内の試作であり、まだ他プレイヤーとの取引はありません。

近所の開拓版では、生還して持ち帰った建材で自分の拠点を育てられます。最初の一戦から木材・石材を持ち帰り、「拠点」で鍛冶小屋を建てると補強費が鉄片2減ります。土地の主を倒して生還すると、その個別の土地に旗が立ち、次の帰還から建材が各1増えます。領域と建材が揃えば住居を建てて最大体力+4。拠点の名前、建物、各土地の開拓状態は再読み込み後も残ります。

各土地は5場面・3戦闘。さらに深層3まで挑めます。現実の時間制限はなく、行動を選ぶまで敵は動きません。戦闘途中でも再読み込みして続けられます。

## ランドマーク発見 — 現実の名所が幻想の地点に変わる（試作）

Crownlessは日記アプリではありません。安全に立ち止まり、現実の散策モードで「近くのランドマークを発見する」を押すと、登録された実在名所の近くなら**幻想の名所が旅の地図に出現し、足跡と印章が付く**。名前・文章・メモの入力は不要です。再訪した場合は同じ名所に足跡が増えます。

現在の試作対象は **東京タワー→紅蓮の望楼、東京スカイツリー→天穿つ白塔、大阪城天守閣→翠冠の王城** の3か所です。対象外の現在地では無関係な架空のスタンプを生成しません。追加の名所は追って拡張します。室内デモでは、これらの名所への訪問と翌日の再訪をGPSなしで試せます。登録済みの名所は従来の拠点周辺64区画から遠くても発見できます。

この版では名所発見時に対応する既存遠征の**地域種別**も解放されますが、ランドマーク固有の戦闘や店舗は未実装です。幻想の旅の地図は模式図であり、現実の座標や徒歩経路を示しません。

GPSは明示操作でのみ取得し、保存するのは発見したランドマークのIDと訪問日です。**正確な現在地、ルート、文章は保存しません**。私的な発見履歴は端末内だけに保存され、サーバー共有はしません。旧日記形式との保存互換はありません。

## 現実の散策

「現実の散策モード」で、安全に立ち止まって拠点の起点を設定します。起点を中心とする約400mの区画ごとに、個別の架空の土地を発見します。同じ区画を再訪すると、その土地の開拓状態が残っています。位置誤差のある区画境界では発見を保留します。歩数や累積距離で通貨は得られません。発見後の遠征は、自宅などの安全な場所から行えます。

- 行き先の指示や実在施設への進入は求めません。地図は架空の模式図です。
- 現在地は明示操作時にだけ取得。精度不足や検出できた移動中の観測は採用しません。
- 正確な現在地を送信・保存しません。再訪のため、起点だけを約100m単位に丸めて端末内に保存します。
- 既存の近所開拓は起点からの区画IDで管理します。新設のランドマーク発見記録は公開名所のIDと訪問日だけを別保存します。GPSの正確な座標、移動軌跡、個人メモは保存しません。
- この試作は拠点周辺の最大64区画まで。地図は領域内でスクロールでき、発見した土地の一覧からも再訪できます。
- バックアップは起点の座標を含みません。別の端末へ移す場合、散策の起点は設定し直します。
- 体験と散策は別セーブ。位置情報を拒否しても体験モードで全ループを遊べます。
- スマートフォンの実GPSにはHTTPSでの配信が必要です。開発サーバーはこのPCのloopback限定です。

Canonical public / phone-playtest URL: [GitHub Pages](https://ryohryp.github.io/crownless/)

今回のSliceはローカル実装です。この作業では公開していません。既存の公開先方針を維持します：Vercel is not the canonical game URL.

## 実装と確認

入口は `index.html` → `expedition.html`。ゲーム本体は `src/slice-engine.js`、画面は `src/slice-app.js`、オリジナルのSVG風景は `src/slice-art.js`、スタイルは `slice.css` です。外部API、外部フォント、ビルド工程はありません。保存は専用キーのlocalStorageで、旧セーブとは独立しています。

```sh
npm test
node --test test/slice-engine.test.js test/slice-app.test.js
```

新規テストは生還と損失、装備差、最終地点への到達、深層、途中保存、GPS精度・移動・遅延応答、保存失敗とタブ競合を確認します。ゲームの面白さは自動テストでは判定できません。

TypeSafe Jev による実ブラウザの高速スモーク確認も任意で実行できます（Node.js 22+ と `TYPESAFE_API_KEY` が必要です）。初回は `npx` が Jev Browser / Chromium を取得する場合があります。

```sh
npm run playtest:browser
```

これは DOM 操作経路の到達性と速度を見るための補助です。スマートフォンUIの触感や「もう1回遠征したいか」の判断は、引き続き実画面プレイで確認します。

[今回のプレイ確認記録](docs/playable-slice-playtest.md) に、実画面で確認した範囲と次の実機プレイの問いを記載しています。

旧 `reboot.html` と旧モジュール・設計書は比較用の履歴として残っています。現在の入口では読み込みません。過去のADRや領土システムの設計は今回のプロダクト方針を上書きしません。
